# Apple asset provenance

The textured OBJ, MTL and PNG are copied from the supplied
`013_apple_berkeley_meshes/013_apple/poisson/` files. They are retained unchanged.
`apple_geometry.obj` contains the same geometry with material references removed
for the green and golden material variants. Original source assets are untouched.

The model uses a uniform scale of approximately 3.4454, giving bounds of
0.2782 × 0.2800 × 0.2427 m. Collision is an approximate bounding box; mass is
1.2 kg and inertia is calculated from that box. These are simulation assumptions.

`apple_smooth.obj` is generated by `scripts/smooth-apple-mesh.py` using positional
vertex welding, 12 Taubin smoothing iterations and area-weighted vertex normals.
The original bounds are restored after smoothing to preserve model dimensions.
All three apples use this visual with SDF material colors: #FF0800, #8DB600 and
#FFFF36. The original mesh and textures remain available unchanged.
